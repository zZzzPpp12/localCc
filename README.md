# Codex Orbit

原生 macOS Codex 套餐额度悬浮工具，薄荷双环界面。SwiftUI + AppKit，无第三方库。当前版本 v0.8.3。

## 运行

推荐使用已安装的 `/Applications/Codex Orbit.app`。构建产物位于 `dist/Codex Orbit.app`。首次启动自动查找本机 Codex CLI，并由 CLI 读取现有的 ChatGPT 登录。

- 当前构建：Apple Silicon（arm64），最低 macOS 13。
- 需要本机已安装 Codex CLI 或包含 CLI 的 Codex / ChatGPT 桌面应用，以及可用的 ChatGPT 登录。
- 应用已作本地 ad-hoc 签名，适合在本机使用，未作 Developer ID 签名和 Apple 公证。
- 这是个人独立工具，与 OpenAI 官方应用没有隶属关系。

## 操作

- **外环薄荷色**：短周期，正常为 5 小时。
- **内环淡紫色**：长周期，正常为每周。
- 球下方两个标签明确对应外环和内环，点击标签切换球心的余量数字。
- 两环始终保留各自周期颜色，低额度通过对应标签的感叹号、球心警示色和系统通知提示，避免两环一起变色后难以区分。
- 点击悬浮球展开两组额度与重置倒计时；再次点击收起。
- 按住侧边小胶囊或自由悬浮球中心拖动即可更改位置。拖动时保持当前形态并暂停自动吸附，松手后吸附最近的左右屏幕边缘、保留新的高度并保存位置；可直接拖到另一侧或其他显示器。单击和小幅指针抖动仍正常打开详情，右键菜单保留。关闭自动吸附及靠边隐藏后可自由摆放。启用自动吸附和靠边隐藏时，窗口偏离边缘也会自行归位；拖动、详情、设置和菜单交互期间暂缓归位，结束后恢复。
- 默认开启**靠边自动隐藏**：靠边停留时收为 12×56 点的窄小入口，贴住屏幕实际左 / 右边界；指针移入入口才展开 108×56 点胶囊及内侧的额度与用量面板。鼠标离开胶囊、详情及两者之间的通道约 0.32 秒后，详情和完整胶囊一起收回窄入口。展开和收回采用约 0.24 秒的缓入缓出滑动，窄入口与胶囊轻柔交叠，详情面板同步淡入淡出。中途重新移入从当前进度反向展开，不跳回起点；拖动时停止过渡，休眠 / 隐藏时停止定时器，系统开启“减少动态效果”时直接切换。隐藏入口完全位于本显示器内，不把窗口移到相邻显示器。停靠模式不再切回大悬浮球。
- 侧边栏按参考图的单个 AI 行展示，固定 108×56 点，不随完整悬浮球的大小设置放大。纯黑圆角背景，OpenAI / Codex 图标进度环在左，5h 剩余百分比在右；移除名称、周期副标题和额外留白。5h 与每周额度在胶囊旁的悬停详情中查看，≤30% 系统通知继续有效。数据未知显示“—”，过期数据变淡。
- 原生窗口尺寸由吸附控制器管理，80% / 100% / 135% 下均验证不会被 SwiftUI 固有尺寸撑大，避免缩小后偏离边缘、无法自动收回。
- 停靠模式下，详情、设置和右键菜单操作均保持小胶囊可见；悬停详情不会显示旧的大悬浮球。关闭自动隐藏后可继续使用自由悬浮球。
- 隐藏状态只保留侧边标签窗口，完整悬浮球窗口不会占住后面的内容；始终保存展开状态的位置，支持多显示器与大小调整。
- 悬浮球右键菜单可刷新、隐藏或打开设置。
- 菜单栏仅显示「提示灯 + 5h 剩余百分比」；≥60% 绿灯、30%–<60% 黄灯、<30% 红灯。绿灯、黄灯带约 2.8 秒一轮的柔和呼吸光晕；红灯为 2.4 秒一轮，光晕稍强，灯芯持续亮起并平滑过渡；三色灯均采用更亮的中心高光与更强的外围光晕；系统开启“减少动态效果”时静止，休眠或熄屏时暂停。缺失或过期读数显示灰灯，悬停说明状态。左键打开额度详情，右键打开完整菜单。隐藏悬浮球后仍能从菜单栏恢复。
- 设置中可调整大小、透明度、外观、刷新间隔和通知。
- 设置 → 启动：通过 macOS `SMAppService.mainApp` 控制“登录 Mac 后自动启动”。系统状态是唯一依据，关闭后不会自行重新启用。需要系统审批时会显示入口，前往系统设置 → 通用 → 登录项与扩展。
- 每周额度 ≤30% 时发送 macOS 系统通知，同一账号、额度组、周重置时间只提醒一次；应用重启不重复。如果启动时已低于阈值且该周尚未提醒，会补发一次。5h 额度使用状态栏提示灯。
- 默认开启**紧凑汽车 HUD 提醒**：固定 216×38 点，单行显示 Codex 图标、5h / 每周、快耗尽 / 已耗尽以及剩余比例；去掉大气泡和多行仪表。提醒与侧边胶囊保持 2 点几何间距、对齐屏幕边缘，详情展开时避让到其上方，顶部空间不足则放下方。重置时间可悬停查看。
- 5h 和每周分别判断：剩余 ≤10% 橙色预警，0% 红色耗尽；轻柔呼吸细边框，系统“减少动态效果”开启时静止。8 秒 / 10 秒自动收起，手动关闭也不抢键盘焦点。隐藏状态暂停动画。
- 每个账号、额度组、周期重置窗口分别去重，快耗尽和已耗尽各一次，重启不重复。首次读数低于阈值也提醒；多周期并发优先已耗尽。未知、过期、断线、退出登录、休眠或已过重置时间的读数不触发。提醒精度取决于真实额度刷新间隔。
- 设置 → 刷新与提醒可开关 HUD，并点击「预览快耗尽 HUD」「预览已耗尽 HUD」查看效果。预览明确标注“样式预览”，使用演示数值，不修改真实额度或提醒去重记录。
- 设置 → 刷新与提醒可开关每周通知和发送测试通知。需要允许 Codex Orbit 的系统通知；本次更新按用户要求开启，今后普通启动不会覆盖用户关闭的设置。
- 未登录时可从详情卡片使用 ChatGPT 浏览器登录；登录由 Codex 管理。

## 悬停用量面板

指针移入侧边窄入口，先显示完整小胶囊，再在朝屏幕内侧展开 372×420 点的薄荷玻璃面板。展开胶囊为 108×56 点，沿侧边保持原高度；移出两者及中间通道约 0.32 秒后恢复 12×56 点窄入口。面板保留设置、打开 Codex、手动刷新和关闭按钮，内容超长时可滚动。

- 顶部显示 Codex、套餐与「剩余 / 已用」切换。5h 使用薄荷色，每周使用淡紫色，分别显示进度、百分比和重置倒计时 / 时间。其他每周额度只在服务端实际返回对应分组时显示。
- Token 趋势来自官方 `account/usage/read` 的每日汇总，提供「今日 / 7天 / 30天」。这不是滚动 24 小时数据；柱形图与合计按服务端返回的日期统计，缺失日期显示未知，明确标注有记录的天数，指针移入柱形可查看单日值。服务端汇总可能延迟，不能用于判断刚刚一次操作的实时消耗。
- 最近四个会话来自 `thread/list` 的本机元数据，按最近更新时间排序，显示名称、项目和累计 Token。只读查询本机 `state_*.sqlite` 中这些会话 ID 的 `tokens_used`；未记录或非正值显示「—」。会话累计值与账号按日趋势属于不同统计范围，不能相加或互相替代。
- 查询使用独立的 App Server 连接，仅在面板展开时按需获取，缓存 60 秒；手动刷新可提前获取。账号变更会清除旧账号缓存，异步结果需再次校验账号才展示。单项统计不可用不影响真实额度读取。
- 不读取对话正文，不扫描会话日志，不修改 SQLite。新增统计与会话元数据仅保存在进程内存；授权 Hook、信任状态及登录项配置沿用现有设置。

## Harness 工作状态与图标动画

当前仅显示 Codex。工作时 OpenAI 图标轻微呼吸，三个薄荷色光点围绕图标转动，约 2.4 秒一轮；额度进度环和百分比保持真实含义、固定位置与尺寸。空闲恢复静态，单会话等待授权暂停思考动画；若另一个会话仍在运行，整体仍显示工作中。设置 → Harness 工作状态可关闭动画，或在设置页预览。

通过本机 Codex 官方生命周期事件接收工作状态：`UserPromptSubmit` 开始、`PreToolUse` 工作心跳、`Stop` 完成、`Interrupt` 中断、`SessionEnd` 结束。多个会话单独跟踪，旧回合的结束消息不停止新回合。回调只传事件类型、匿名会话哈希、回合标识和时间，不发送提示词、命令、路径或回答，也不修改任何授权决定。

每个状态 Hook 使用相同的 `--activity-hook` 入口，返回空 JSON，不阻塞或批准任务。安装器保留既有 Hook 的内容和顺序，尤其保持已信任的 `PermissionRequest` 定义不变；新增状态 Hook 仍需用户在 `/hooks` 审阅信任后，重新打开 Codex 会话加载。

来源范围是启用这些 Hook 的**本地 Codex harness**；云端编排、远程主机和未加载 Hook 的旧会话不保证提供事件。启动时状态为“待同步”，没有可靠事件时不假装工作。10 分钟未见工作心跳会转为未知，避免客户端崩溃或丢失结束事件后永远旋转。事件状态仅在内存保存，重启等待新信号。

动画最高 20 fps，仅工作且胶囊可见时运行；隐藏、熄屏、休眠或关闭动画时暂停。macOS 开启“减少动态效果”时保留静态工作标识。

```sh
"dist/Codex Orbit.app/Contents/MacOS/CodexOrbit" --activity-self-test "$PWD/qa/activity-ui-report.json"
```

本机验收导出 `thinking-preview.gif`（演示状态，非真实额度），覆盖动画帧变化、真实 Timeline 定时、减少动态效果、多会话、结束 / 等待切换，以及状态回调不产生授权决定。

## Codex 操作授权联动

通过官方同步 `PermissionRequest` Hook 将待授权操作交给 Orbit，支持本机 Codex 在该 Hook 覆盖范围内发出的命令、文件修改、MCP / 网络授权。它不连接或拦截其他进程的私有 stdio，不接管 macOS 密码、系统隐私权限或网页登录弹窗。远程主机、已有回合及未重新加载 Hook 的会话不保证可接收。

- 待授权时，胶囊下方显示 136×34 点的小标签；点击才打开 332×280 点详情卡，自动避让普通悬停额度详情。
- 卡片显示工具名称、说明、目录、会话 / 回合标识及**完整工具参数**，支持滚动和复制。参数超出 256 KiB 时交回 Codex，不截断后继续授权。
- 「允许一次」仅返回当前请求的官方 allow 决策；「拒绝」返回 deny；「回 Codex 处理」不返回授权决定。没有自动同意、会话永久许可或命令改写。
- 最多 8 项排队；展示中的请求失效时收起卡片，新请求须重新展开。确认按钮绑定请求 UUID，避免旧按钮确认了新请求。
- 等待 120 秒未处理，或请求被取消、Hook 进程断开、Orbit 退出 / 休眠、关闭联动时，交回原有 Codex 授权。其他 Hook 或管理策略的拒绝仍以 Codex 的最终决定为准。
- 通过私有 Unix Socket 通信：目录权限 0700、Socket 0600，双方校验相同 macOS 用户。授权内容仅保留在内存，不记录到文件、不上传。

安装后在设置 → Codex 操作授权可安装 / 更新 Hook 或预览卡片。安装过程备份 `~/.codex/hooks.json` 并仅合并 Orbit 的 PermissionRequest 处理器，保留其他 Hook，不写入信任哈希。**必须由用户在 Codex 的 `/hooks` 审阅并信任新增 Hook，然后重新打开会话 / 重启对应 Codex 客户端使其加载。** 未信任前不会执行，因此不能宣称已拦截真实会话授权。

依据：[官方 Hooks 文档](https://learn.chatgpt.com/docs/hooks)。本机隔离验收只往返授权 JSON，不执行示例命令，不代替用户信任 Hook：

```sh
"dist/Codex Orbit.app/Contents/MacOS/CodexOrbit" --approval-self-test "$PWD/qa/approval-ui-report.json"
```

## 真实数据与边界

通过官方 Codex App Server 的 stdio JSON-RPC 协议读取：

1. 启动本机 `codex app-server --listen stdio://`。
2. 完成 `initialize` / `initialized` 握手。
3. 读取 `account/read`，确认当前 ChatGPT 账号。
4. 调用 `account/rateLimits/read`，优先解析 `rateLimitsByLimitId`。
5. 默认 90 秒刷新，可设置 60 / 90 / 120 秒。更新通知触发完整重读；不能将独立进程的通知视为整个账号的全局推送。

余量按 `clamp(100 - usedPercent, 0, 100)` 计算。周期名称根据 `windowDurationMins` 动态显示；`resetsAt` 为 Unix 秒。窗口缺失显示未知，不显示假零。倒计时归零后等待服务端更新，不自行把余量改成 100%。

网络或服务失败时保留当前进程最近一次成功读数并明确标为过期；失败指数退避，最长 10 分钟。休眠暂停子进程，唤醒重新连接。账号变更清除旧数据。API Key 登录不能用于显示 ChatGPT 套餐额度。

应用不创建 Codex 对话、不发起模型任务、不自动消费额度重置券、不读取或保存 auth.json 的内容、不记录原始 RPC 数据或服务端日志。登录凭证继续由 Codex 自己管理。授权联动使用本机私有 Unix Socket。另在本机 UserDefaults 保存偏好、HUD 及每周通知去重标记（哈希标识与重置时间，不含原始账号信息）；额度、Token 趋势及最近会话读数不持久化到磁盘。

CLI 版本升级可能改变协议。当前本机验证版本为 `codex-cli 0.163.0-alpha.11`。自定义 CLI 路径可在设置中选择；留空恢复自动查找。

## 源码构建与验证

需要 Xcode 或 Command Line Tools：

```sh
bash scripts/build.sh
bash scripts/test.sh
```

构建输出为 `dist/Codex Orbit.app`。脚本为当前机器架构构建，使用系统 Swift 和框架，并作 ad-hoc 签名。

独立应用的数据连通性诊断（输出不含邮箱和认证信息）：

```sh
"dist/Codex Orbit.app/Contents/MacOS/CodexOrbit" --diagnose
```

原生界面验收（读取真实额度，导出应用自己的界面，随后退出）：

```sh
"dist/Codex Orbit.app/Contents/MacOS/CodexOrbit" --smoke-test "$PWD/qa" --quit-after-smoke
```

侧边隐藏的原生窗口控制验收：

```sh
"dist/Codex Orbit.app/Contents/MacOS/CodexOrbit" --edge-self-test "$PWD/qa/edge-ui-report.json"
```

滑动动画的原生定时、反向过渡、拖拽打断和减少动态效果验收（导出使用演示额度的 GIF）：

```sh
"dist/Codex Orbit.app/Contents/MacOS/CodexOrbit" --edge-animation-self-test "$PWD/qa/edge-animation-report.json"
```

自启动必须在安装后的应用中开启；开发目录内的构建不会注册自身，以免登录时启动错误副本。安装自动化可首次从 `/Applications/Codex Orbit.app` 启动并传入 `--enable-login-item --installation-report <路径>`，报告会记录系统返回的实际登录项状态。

安装时可传入 `--enable-weekly-alert` 请求开启每周通知；`--installation-report <路径>` 会记录系统通知授权与提醒开关状态。诊断及界面验收模式不会发送真实额度通知或更新真实 HUD 去重记录。

HUD 原生窗口验收（隔离测试偏好，测试短时自动收起、跨周期告警与去重）：

```sh
"dist/Codex Orbit.app/Contents/MacOS/CodexOrbit" --hud-self-test "$PWD/qa/hud-ui-report.json"
```

`qa/` 是本地验收产物，设置界面截图可能包含当前账号邮箱，悬停面板截图可能包含本机会话标题；不包含在发布压缩包中。

协议来源：[Codex App Server 官方文档](https://learn.chatgpt.com/docs/app-server)。

侧边胶囊的布局参考用户提供的 [Agent HUD Simple 模式](https://github.com/jazzenchen/agent-hud-open) 与样式图，以原生 SwiftUI 实现。Codex 使用参考仓库中共享的 OpenAI / ChatGPT 品牌图标；来源说明与 LobeHub MIT 许可随应用一起保存在 `Contents/Resources/ProviderAssets`。
